
# Portfolio personal - Daniel Quintero Díaz

Este repositorio contiene mi portfolio web personal,
desarrollado como parte de la Práctica 3 de Control
de Versiones y Flujos de Trabajo de 2º DAW.

## Sobre el proyecto

El objetivo es presentar mi perfil como estudiante
de Desarrollo de Aplicaciones Web, mis conocimientos
y algunos de los proyectos que he desarrollado.

La página está publicada utilizando GitHub Pages.

## Tecnologías utilizadas

- HTML5: estructura de la página web.
- CSS3: diseño y estilos visuales.
- Git: control de versiones.
- GitHub: alojamiento del repositorio.
- GitHub Pages: publicación de la página.

## Contenido

- Presentación personal.
- Tecnologías y conocimientos.
- Proyectos con enlaces a GitHub.
- Enlace a mi perfil de GitHub.
